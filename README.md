# DYSTORE — Original Quality Video Lab

Mobile-friendly video patcher inspired by the user's desired workflow.

## Processing mode

DYSTORE uses the NoBlur container/sample-table patch workflow. It does **not** re-encode the video, so the original video data is preserved.

- Upload MP4/MOV
- Process locally in the browser/device
- Download the patched MP4
- No server upload in the app

## Important

This is not a transcoder. The patch changes MP4 container/sample-table structures rather than recompressing the video. Platform compatibility can vary because some services validate MP4 containers differently.
