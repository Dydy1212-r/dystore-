# DYSTORE v1

A standalone mobile-friendly dystore dashboard.

Included:
- Dark purple/cyan responsive UI
- Video upload MP4/MOV
- Local browser metadata inspector
- Patch workflow UI with progress
- Patch history UI
- Subscription cards
- Dashboard/account area
- How-to section

## Deploy
Upload `index.html`, `style.css`, and `app.js` to GitHub/Vercel.

## Important
The patch button is a frontend workflow placeholder. Connect your own NoBlur/client-side processing module in `app.js` to perform the real patch. TikTok login/upload and payments require your own official API/auth/payment setup.
